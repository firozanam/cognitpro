# CognitPro

An AI prompt marketplace: sellers publish and moderate prompts, buyers
purchase them by card or take them for free, and the platform keeps a 15%
commission on every completed sale.

Built as a Laravel 12 modular monolith serving an Inertia v2 + React 19 +
TypeScript SPA — there is **no REST/JSON API layer**; every route is a web
route returning an Inertia response.

## Features

- **Marketplace** — browse, search, sort, and featured prompts; prompt
  detail pages with reviews and ratings
- **Selling** — create prompts as drafts (fixed, pay-what-you-want, or free
  pricing), submit for admin moderation, track sales and earnings
- **Buying** — per-user cart for fixed-price prompts, direct checkout for
  pay-what-you-want, instant acquisition for free prompts
- **Payments** — Stripe PaymentIntent card payments with signed-webhook
  completion; abandoned pending purchases expire after 24 hours
- **Reviews** — buyers review purchased prompts; sellers respond; helpful
  votes
- **Accounts** — registration with email verification, password reset,
  two-factor authentication, profile settings
- **Administration** — prompt moderation (approve / reject with reason /
  feature) and user management (ban / unban)

## Tech stack

| Layer    | Technology |
|----------|------------|
| Backend  | Laravel 12 (PHP 8.2+), Fortify session auth, PHPUnit |
| Frontend | Inertia v2, React 19, TypeScript, Tailwind CSS v4, shadcn-style components |
| Payments | Stripe (`stripe/stripe-php`) |
| Database | SQLite by default (MySQL/Postgres supported) |
| Queue    | `database` driver — a worker is required in production |

## Requirements

- PHP 8.2+ with the [Laravel-compatible extensions](https://laravel.com/docs/12.x/deployment#server-requirements)
- Composer, Node.js + npm
- SQLite (default) or another Laravel-supported database
- A Stripe account for card payments (optional in local development —
  unconfigured Stripe shows a graceful error instead of charging)

## Quick start

```bash
composer setup   # composer install, .env, key, migrate, npm install + build
composer dev     # Laravel server + queue:listen + pail + Vite
```

Then open `http://localhost:8000`. `composer setup` does **not** seed
anything; to load the demo dataset:

```bash
php artisan db:seed                # appends demo users, prompts, reviews
php artisan migrate:fresh --seed   # clean slate, then seed
```

### Demo accounts (local only)

The seeder refuses to run in production. In local/testing it creates:

| Account | Email | Password (env override) |
|---------|-------|------------------------|
| Admin | `admin@cognitpro.com` | `password` (`SEED_ADMIN_PASSWORD`) |
| Seller | `seller@test.com` | `password` (`SEED_SELLER_PASSWORD`) |
| Buyer | `buyer@test.com` | `password` (`SEED_BUYER_PASSWORD`) |

### Stripe

Set `STRIPE_KEY`, `STRIPE_SECRET`, and `STRIPE_WEBHOOK_SECRET` in `.env`,
then forward webhooks locally:

```bash
stripe listen --forward-to localhost:8000/stripe/webhook
```

Subscribe at minimum to `payment_intent.succeeded` and
`payment_intent.payment_failed`. See
[ARCHITECTURE.md](ARCHITECTURE.md#purchase-and-payment-flow) for the full
payment flow.

## Testing and quality gates

```bash
composer test          # config:clear + pint --test + the PHPUnit suite
vendor/bin/phpunit --filter=CartTest
npm run types          # tsc --noEmit
npm run lint           # eslint
npm run format:check   # prettier
```

Tests run on SQLite `:memory:` with array cache/session/mail and a sync
queue — no external services needed. CI (GitHub Actions) runs the lint
gate on PHP 8.4 and the PHPUnit suite on PHP 8.4/8.5 after a frontend
build. There is no deploy pipeline in this repository.

## Project structure

```
app/Modules/        # Core, Auth, User, Prompt, Payment, Admin modules
  └── Providers/    # module service providers load each module's routes
app/Policies/       # PromptPolicy
database/seeders/   # demo dataset (env-gated)
resources/js/       # Inertia pages mirroring the modules
resources/css/      # Tailwind v4 theme tokens (light + dark)
docs/               # internal audit report (git-ignored)
```

Frontend conventions: shared domain types in
`resources/js/types/prompt.ts`, formatting helpers in
`resources/js/lib/format.ts`, all colors from the theme tokens in
`resources/css/app.css`. `resources/js/routes/` is generated by Wayfinder —
regenerate, never hand-edit.

## Deployment

Inertia SSR is disabled — the app ships client-side rendered. For the full
checklist (queue worker, scheduler, security settings, backups), see the
[operations runbook](ARCHITECTURE.md#operations-runbook). Summary:

```bash
composer install --no-dev --optimize-autoloader
npm ci && npm run build
php artisan migrate --force
php artisan queue:work --tries=3   # supervise this — notifications are queued
```

Set `APP_ENV=production`, `APP_DEBUG=false`, and
`SESSION_SECURE_COOKIE=true` behind HTTPS. A cron entry must run
`php artisan schedule:run` every minute (it expires stale purchases daily).
